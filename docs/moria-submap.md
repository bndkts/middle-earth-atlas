# Moria regional map

Clicking Moria on the world map (or choosing it in search) loads `/maps/moria/`.
The Maps menu and the return link load the world map again; its saved viewport
is retained. Existing `/?place=moria` links still show the place panel, which
includes a link to the regional map. Choosing Moria as a directions endpoint
continues to work. Reading-mode spoiler protection is preserved.

The regional map supports pointer drag, two-finger pinch, keyboard panning,
zoom buttons, fit-to-view, label visibility and nine addressable landmarks.
Landmark selections use URL fragments and browser Back/Forward. Without
JavaScript, the illustration, index, all descriptions and return links remain
available. A fresh offline cache includes the regional map and its assets.

## Artwork and maintenance

The original SVG plate is drawn by `scripts/draw-moria.mjs` and generated by
`npm run generate` into `assets/moria-section.svg`. Do not edit the output.
Its 1500 × 1000 viewBox is an illustration coordinate system, with a 3000 × 2000
intrinsic image size. The camera operates on the viewBox coordinates; landmark
anchors in `maps/moria/index.html` are percentages of that same plate. Artwork
metadata is in `window.ATLAS_MAP_IMAGES` in `src/images.js`.

The SVG is self-contained: no raster images, scripts, filters or external fonts.
Tests enforce deterministic generation and a 600 KB ceiling. Gesture frames
only update the plate transform, inverse marker scaling and zoom controls.
Viewport dimensions are measured at resize and gesture start, not after writes
inside pointer-move handlers. Pointer cancellation, focus loss and resize clear
active gestures.

## Interpretation and sources

This is an imagined west–east section, with north–south differences projected
onto the same plane. Architecture, tunnel connections and dimensions are
invented. The plate combines periods and depicts the bridge intact. It has no
timeline and does not claim to be an authentic dwarven document or Tolkien map.
These caveats are also available next to the map.

Reading references: *The Fellowship of the Ring*, Book II, “A Journey in the
Dark” and “The Bridge of Khazad-dûm”; *The Two Towers*, Book III, “The White
Rider”. Secondary references used to locate and check those relationships:

- [Seventh Level](https://www.glyphweb.com/arda/s/seventhlevel.html): the
  Twenty-first Hall and Mazarbul above the gates; the limits of a reconstruction.
- [Second Hall](https://tolkiengateway.net/wiki/Second_Hall): the First Deep,
  bridge and eastern exit sequence.
- [Endless Stair](https://tolkiengateway.net/wiki/Endless_Stair): the ascent from
  the deepest dungeon to Durin’s Tower on Celebdil.

Each landmark description links to additional reading. Text and positions
should retain these uncertainty notices when revised.
